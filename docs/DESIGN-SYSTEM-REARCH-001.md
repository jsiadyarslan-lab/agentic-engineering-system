# DESIGN-SYSTEM — AES-FACTORY-CONSOLE-REARCHITECTURE-001 §6

نظام التصميم الموحد لغرفة التحكم المؤسسية. **مصدر الحقيقة للقيم:** `src/ui/theme.css` (توكنز مقفلة باختبار) — هذه الوثيقة تشرحها وتحدد قواعد الاستخدام، و`src/ui/console.css` هي طبقة المكونات فوقها.

## 1. مبادئ

1. **غرفة تحكم لا محادثة:** الصفحة الافتراضية مركز القيادة (A–F)؛ المحادثة قناة عمل مستقلة.
2. **صدق تشغيلي:** كل رقم من API حي. الغياب يُعرض «غير متاح/لا شيء بعد» — لا قيمة مختلقة، ولا `CONNECTED` يوحي بجاهزية: اتصال الخادم وجاهزية الوكلاء مؤشران منفصلان دائمًا.
3. **توكنز حصرًا:** لا ألوان أو مسافات أو ظلال جديدة خارج `theme.css`.
4. **G7:** صفر تباعد حروف على النص العربي؛ الترقيم حكر على السياقات اللاتينية (mono/ltr).
5. **G3:** كل قيمة رقمية تقنية بخط IBM Plex Mono مع `tnum`.

## 2. Typography Scale (من theme.css)

| الرمز | الاستخدام |
|---|---|
| `--fs-28/--fs-display` | عناوين البطل فقط (شبه غير مستخدمة في غرفة القيادة) |
| `--fs-17` | عناوين التشغيل الحالي وأسماء المشاريع البارزة |
| `--fs-14` | عناوين الأقسام `.cmd-section-title` وعناوين الصفوف |
| `--fs-13` | النص الأساسي للبيانات (قيم الجداول، الوصف) |
| `--fs-12` | القيم الرقمية في شريط الحالة، التسميات الثانوية |
| `--fs-11` | مفاتيح الخلايا والتسميات الدقيقة |

الوزن: 700 للعناوين، 600 للقيم، 400 للنص. الأرقام دائمًا `--font-mono` + `direction:ltr; unicode-bidi:isolate` + `tnum`.

## 3. Spacing Scale

`--sp-1..2..3..4..5..6..8` (خطوة 4px). قواعد الاستخدام: داخل البطاقات `--sp-3/4`، بين الأقسام `--sp-5/6`، حشوة صفحة مركز القيادة `--cmd-gutter = --sp-5` (تصير `--sp-4` عند 1366).

## 4. Grid & Layout Widths

- **الصفحة المؤسسية:** عمود واحد بعرض أقصى `1280px` متمركز (`.cc-view .cc-body`) — كثافة قراءة مؤسسية بلا امتداد مفرط.
- **شريط الحالة:** صف مرن من خلايا `min 148px` يلف أفقيا مع تمرير مخفي على الضيق.
- **التشغيل الحالي (B):** شبكة `1.4fr + 3×1fr` (التحديد الرئيس + 3 خلايا)، على الهاتف `1fr 1fr` والبطاقة الرئيسة بعرض كامل.
- **صحة المصنع (E):** `auto-fit minmax(230px, 1fr)`.
- **الشريط الجانبي:** `--sidebar-width` ثابت على سطح المكتب؛ ≤900px يتحول **درجًا حقيقيًا** (طبقة علوية + خلفية معتمة).

## 5. Card Hierarchy

| المستوى | السطح | الاستخدام |
|---|---|---|
| L0 | `--bg-canvas` | خلفية العمل |
| L1 | `--bg-sidebar` / `--bg-raised` | الشريط الجانبي / البطاقات والأقسام `.cmd-section` |
| L2 | `--bg-hover` | التحويم والقوائم والشارات |
| حدود | `--border-subtle` عادية · `--border-strong` حقول | حدّان فقط — تقليل التكرار البصري |

## 6. Border & Radius System

`--radius-s` عناصر صغيرة (أزرار أيقون) · `--radius-m` البطاقات والجداول و`.cmd-radius` · `--radius-pill` الرقائق `.ent-chip`. الحدود: `1px` دائمًا؛ لا ظلال داخلية على البطاقات العادية.

## 7. Shadows & Elevation

`--shadow-1` طفو خفيف · `--shadow-2` منبثق · `--shadow-modal` النوافذ والدرج. **لا ظل زينة:** الظل يدل على طبقة فوق المحتوى فقط (درج/نافذة/شريط مثبت).

## 8. Semantic Colors

| الوظيفة | التوكن | الاستخدام |
|---|---|---|
| إجراء أساسي/نشط | `--accent` (#58A6FF) + soft/border/ink | الأزرار الأساسية، الحالة الحية، الروابط، حلقة التركيز |
| نجاح/اعتماد | `--ok` | VERIFIED، READY، جاهز بالفحص |
| تحذير/انتظار | `--warn` | بانتظار قرار المالك، UNTESTED مؤقت، ركيزة بلا عزل |
| فشل/حجب | `--danger` (+`--danger-hi` للنص) | BLOCKED/FAILED، انقطاع الاتصال |
| معلومة | `--info` | جاهزة (READY كحالة مشروع) |
| محايد | `--text-muted/--text-faint` | لا شيء بعد، معلومة غير متاحة |

## 9. Status Indicators

- نقطة `.cmd-dot` بأربع حالات: `ok/live (هالة نابضة)/warn/err/idle`.
- رقائق `.ent-chip` لكل حالة مشروع/حدث بتسمية عربية صادقة من `STATUS_LABELS`.
- **قاعدة الفصل:** «اتصال الخادم» خلية مستقلة عن «الوكلاء الجاهزة» وعن «تشغيلات نشطة» — لا يُدمج مؤشر أبدًا.

## 10. Buttons & Inputs

أزرار: `.btn primary` (أزرق صلب بنص `--accent-ink`) للإجراء الحاسم الوحيد في السياق (اعتماد/تحقق/إنشاء) · `.btn ghost` للثانوية (فتح/أرشفة/تحديث) · `.icon-btn` للأدوات. حقول: `.ent-input/.ent-search/.ent-select` على `--bg-input` بحد `--border-strong` وتركيز بحلقة `--focus-ring`.

## 11. Tables & Data Density

`.ent-table` الجدول المؤسسي الوحيد: رأس على `--bg-sidebar`، صفوف `9-10px` عموديًا (`fs-13`)، تحويم صف على `--bg-hover`، أرقام mono. **على ≤720px يتحول الصف بطاقة عمودية** وكل خلية تحمل تسميتها من `data-k`.

## 12. Empty / Loading / Error States

- `.cmd-empty` (عنوان + تلميح + إجراء اختياري): يعلن السبب ويقترح الخطوة التالية — «لا مشاريع بعد — أنشئ أول مشروع…».
- `.cmd-loading` دوّار قياسي + نص المصدر («جارٍ تجميع حالة المصنع من المصادر الحية…»).
- `.cmd-flash` نتيجة إجراء (ok/err) مؤقتة أعلى القسم.
- `.ent-error` عنوان + رسالة الخطأ الحقيقية + زر إعادة المحاولة.

## 13. الحركة

`--dur/--ease` للتحولات الوظيفية فقط (درج، تحويم، شريط تقدم، دوّار تحميل). **لا حركة زينة.**

## 14. Responsive Architecture (§7)

| المقاس | السلوك |
|---|---|
| 1600×900 | العرض الكامل؛ جدول المشاريع بكل الأعمدة |
| 1366×768 | حشوة أضيق؛ الشبكات تلتف (`auto-fit`) |
| 390×844 | الدرج الحقيقي: يُغلق عند اختيار سطح + نقر خارجي + زر إغلاق + Escape؛ الجداول بطاقات؛ شريط الحالة بتمرير أفقي مخفي؛ أزرار القرار قابلة للاستخدام |

الممنوع: لقطة هاتف بقائمة مفتوحة تغطي المحتوى تعتبر دليلًا غير مقبول — الصورة بعد الإغلاق حصرًا.
