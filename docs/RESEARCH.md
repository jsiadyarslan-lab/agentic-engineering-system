# طبقة البحث — مزودون قابلون للتوفير

> الأمر 010 §23-§26: «الإنترنت» ليس قدرة واحدة. البحث والجلب وDNS
> وHTTPS وHTTP وBrowser قدرات مستقلة، والبحث نفسه مجموعة مزودين —
> DDG مهلة ≠ الإنترنت مقطوعًا.

## المصفوفة (كل قدرة بمسبارها الحقيقي)

| القدرة | ما تفحصه فعليًا |
|---|---|
| `web_search` | بحث حقيقي بأول مزود جاهز بنتائج قابلة للتحليل |
| `web_fetch` | جلب صفحة موثوقة واستخلاص نصها |
| `network_dns` | حل اسم حقيقي |
| `network_https` | اتصال TLS حقيقي (443) |
| `network_http` | HTTP GET مباشر (80) — منفصل عن HTTPS |
| `browser` | غير منفذة — UNAVAILABLE دائمًا (لا READY زائفة) |

## مزودو البحث الثلاثة (كل واحد تنفيذ فعلي)

| المزود | يتطلب | متى تستعمله |
|---|---|---|
| **DuckDuckGo** | لا شيء (افتراضي) | حين تكون الشبكة تصل إليه |
| **SearXNG** | رابط مثيل (مثلك الخاص أو موثوق) | عند حجب DDG — JSON API |
| **Search API** | نقطة نهاية + مفتاح | tavily / brave / صيغة عامة |

### التجهيز من الواجهة

```
الإعدادات ← الأدوات والقدرات ← مزودو البحث
  SearXNG:  رابط المثيل ← حفظ التكوين ← تفعيل ← فحص حقيقي
  Search API: نقطة النهاية + النمط + المفتاح (للمخزن المحلي) ← فحص
```

المفتاح يُخزن في مخزن الأسرار المحلي (`research::<name>`) ولا يعاد من
أي نقطة نهاية أبدًا.

## عقد الفشل (مصنف لا مجمل)

- نقل فاشل (مهلة/شبكة) → `DEPENDENCY_FAILURE / PROVIDER_NOT_READY`
  مع اسم المزود.
- النقل نجح والصفحة بلا مادة → `TOOL_FAILURE / RESULTS_NOT_ANALYZABLE`
  مع عدادات الاستخلاص (page_chars/links/snippets).
- كل المزودين فاشلون → خطأ واحد **يفصل** حالة كل مزود:
  «DuckDuckGo: مهلة؛ SearXNG: غير مُعد؛ API: بلا نقطة» — لا «الإنترنت
  مقطوع».

## قرارات preflight الواعية

- هدف يطلب البحث جوهريًا (OSINT/مصادر/رصد) + لا مزود جاهز → **BLOCKED**
  للبحث وحده، مع إجراء مالك يسمي مسار التوفير.
- هدف بلا بحث (جلب مباشر) + الجلب READY → **يمر** — الجلب لا يحجب
  بغياب البحث أبدًا.
