## القوانين الحاكمة (مدققة آلياً في `src/cockpit9_checks.py` — 53/53)

1. **رمادي صرف**: أي لون غير رمادي في أي CSS يُحول إلى رمادي الإضاءة المكافئ عند البناء، والفحص يرفض أي hex بـ R≠G≠B.
2. **لا بث مستعار**: إعادة التشغيل ظلية من اللقطة المجمدة معلنة على واجهة القمرة نفسها — مفتاح الأمانة يصرّح بسبعة بنود بما فيها حدود العرض.
3. **المرجع الذاتي الصادق**: حجم الملف الذاتي المحقون يساوي حجمه الفعلي على القرص (بناء تكراري حتى التطابق)، وبصمته لا تُطبع داخله عمداً (لا مرجع ذاتي متسق ممكن).
4. **سجل حقيقي حرفي**: رسائل المالك في المحادثة منقولة حرفياً من السجل الفعلي.
