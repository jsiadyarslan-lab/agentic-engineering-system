## 2. النظام البصري (مخرج 3.2 — المواصفة الملزمة للتنفيذ)

### 2.1 الرموز — theme.css كمصدر حقيقة واحد مكتمل

- **أسطح (كما هي — مقيسة جيدة):** bg #0D1014 / sidebar #10141A / raised #141920 / elevated #1B222A / input #161C24 / hover #1F2731.
- **نصوص — أرضية AA مضمونة رقميًا:** text #F0F3F6 (17.1:1) / mid #A6B0BC (8.7:1) / dim #8D99A6 (هدف ≥5.5:1 على bg) / **faint يُقصى من المحتوى** ويُعاد تأهيله كـ`--text-disabled` للعناصر المعطلة فقط (معفاة من AA) — placeholder يرثع `--text-dim`.
- **تمييز:** الذهبي المؤسسي #D4AC55 (8.9:1) بكل مشتقاته + **رمز دلالي جديد `--accent-agent #58A6FF`** (من مرجع 003) حصريًا لدلالة «حيوية الوكيل/النظام» (شارة LIVE، نبض النشاط) — فيصبح أزرق المصنع مواطنًا دلاليًا في النظام الواحد لا جزيرة.
- **دلالي:** ok #5CB87A / danger #E06C5F / warn #D9A03F / info #5B9BD5 + soft/border/chip (كما هي — كلها AA على bg).
- **خطوط (جديد — كان الغائب):** `--font-sans` كامل و`--font-mono` موحد (IBM Plex Mono أولاً) — تنتهي مداخل mono الخمس.
- **مقياس الطباعة (جديد):** 11 (وسم علوي صغير فقط) / 12 وصف / 13 تنقل+ثانوي / 15 جسم / 17 عنوان بطاقة / 19 رأس قسم / 22 ترحيب فرعي / 28 ترحيب رئيس. أوزان 400/500/600/700 بانضباط: 600+ للعناوين فقط.
- **مسافات:** شبكة 4px القائمة (sp-1..10) مع **إلزام استخدام** في القيم الجديدة.
- **أنصاف أقطار:** 6/10/14/pill كما هي.
- **z (سلّم واحد):** content 30 / raised 40 / sidebar 50 / sticky 55 / drawer 61 / drawer-panel 62 / modal 70 / popover 71 / boundary 300 — تُستبدل كل القيم الحرفية.
- ** breakpoints (موثقة):** 480 (تدقيق صغير) / 720 (تخطيط جوال) / 900 (طي الشريط — مطابقة لـJS) / 1100 (أعمدة المصنع) — و800 في المصنع تُوحَّد إلى 900.
- **حركة:** ease/dur القائمة + dur-slow 0.32s للأدراج + prefers-reduced-motion شامل (قائم يُعمَّم).

### 2.2 المكوّنات الموحدة (توحيد بالبناء لا بإعادة التسمية)

الاستراتيجية: **تبقى أسماء الفئات القائمة** (عقود اختبار + 74 عقد بنية) لكن قواعدها تُبنى كلها من نفس الرموز ونفس القواعد الهندسية — فتصبح «ستة أنظمة أزرار» **تطبيقات** لنظام زر واحد:

- **زر واحد:** ارتفاع 34px (صغير 28px)، نصف قطر 8px، أساسي = ذهبي صلب بنص داكن (AA 8.7:1)، ثانوي = سطح مرتفع بحد، شبح = نص بلا صندوق. كل عائلات .btn/.pv-btn/.pl-btn/.mp-btn/.pl-act-btn/fc-btn تتقاذف نفس القيم.
- **حالة واحدة:** نقطة 8px (بنفس الهندسة أينما ظهرت: status-dot/pj-dot/proj-run-dot/cc-run-dot) + حبة نص 11px بعلو 20px بلون دلالي موحد.
- **تبويب واحد:** نص 13px/600، خط سفلي 2px ذهبي للنشط — settings-tab وpl-tab وfc-tab نفس القواعد.
- **حالة فراغ واحدة:** علامة أيقونية 40px باهتة + عنوان 15px/600 + سطر إرشاد 13px + فعل اختياري — cc-empty/env-empty/fc-empty/gen-loading/pl-state نفس الهيكل.
- **عزل BiDi (جديد):** قاعدة `.tech` — `dir=ltr, unicode-bidi:isolate, font-mono` تُطبق على السلاسل التقنية (مسارات/رموز حالة/أسماء مزود) في الرسائل والبطاقات.
- **md-body واحدة:** طباعة موثقة للعناوين/القوائم/الجداول (رأس بحد سفلي لا خلفية صاخبة، خلايا padding 8/12، أعمدة minmax منطقية)/كود بخلفية أغمق وعزل LTR — تُصبح app-shell.css المرجع وlive.css يورّثها.

### 2.3 الشاشات (مخرج 3.3 — ما يتغير فعليًا)

1. **الترحيب:** بطل مُهيكل — علامة أصغر، h1=28/700، سطر تعريف 15/mid، بطاقتا اقتراح (أيقونة+عنوان+وصف 13px) بحدود تفاعل صريحة — يملأ المساحة بنية لا فراغ.
2. **الشريط الجانبي:** إيقاع 4px منضبط، تسميات التنقل 13px (كانت 12.5 — إصلاح الهرمية المقلوبة)، رؤوس أقسام 12px/600 متباعدة، شارات موحدة.
3. **المحادثة:** طباعة المساعد المطورة (md-body الجديدة)، الفقاعة المستخدمة أضيق تركيزًا، meta موحّد.
4. **المحرر:** عرض متطابق مع عمق الرسائل (إصلاح S-15)، ارتفاع موحد، حلقة تركيز ذهبية، تلميح اختصارات باهتًا تزامنيًا.
5. **لوحة الإعدادات:** تبويبات الخط السفلي الموحدة، عناوين أقسام 17/600، بطاقات مزودين بحدود AA.
6. **التشغيلات/الأرشيف:** إعادة كتابة control-center.css نقية الرموز (سقوط بقايا اللوحة الفاتحة) — بطاقات بحالة موحدة.
7. **المصنع:** نفس الهيكل المُجزَّء المرجعي (بطاقات/حبوب/إشعار بحافة داخلية — مفردات 003 البنائية تبقى) لكن قيمه كلها من الرموز العالمية: أسطح فحمية لا كحلية، liveness بأزرق الوكيل الدلالي، خطوط/أنصاف/مسافات النظام الواحد، رأس موحّد مع بقية cc-head، شبكة إحصاءات مضغوطة 2×2.
8. **عرض المشروع:** تبويبات موحدة، سقوط طبقة الترقيع الداكن (الجذر أُصلح)، بطاقات pl-card بحدود رمزية موحدة.
9. **الجوال (720):** نفس اللغة بحشوات أضيق؛ الشريط overlay؛ المحرر بلا قص (مقيس قائمًا — يُصان).

### 2.4 صون سلامة التطبيق (مخرج 3.4 — الحدود الصلبة)

- **لا يتغير:** أي عقد API، أي معرف DOM (اختبارات 005 تُشتق كل $() آليًا)، ترتيب DOM للمحرر (send→input→plus)، ترتيب تحميل الأصول و?v=4.0.0، كل السلاسل العربية المختبرة، علامات المراحل ✓●○✕، فئات .pj-exec-gate/.pj-policy/.host-truth/.env-compat (projects.css) وعائلة .pj-job*/hjBeat (harness.css)، `max-width: 920px` و`.bubble.assistant` و`align-self: stretch` (app-shell.css)، عقد النحافة: **styles.css < 1200 (إصلاح الخرق القائم 1513)**.
- **إصدار:** يبقى 4.0.0 على فرع المرشح (رفعُه قرار إصدار للمالك عند الدمج؛ cache-control: no-cache يمنع تقادم الأصول).
- **إصلاحات وظيفية موثقة مستقلة:** BUG-01 (_obj) وBUG-02 (تغليف renderEvent) وBUG-03 (مستمع resize) وBUG-04 (فراغ محادثة) — كلها أخطاء واجهة صرفة لا تمس منطق المصنع.
