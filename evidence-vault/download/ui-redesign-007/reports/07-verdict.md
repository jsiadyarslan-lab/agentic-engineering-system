## 2. مطابقة معايير القبول (المرحلة 6)

**جودة التصميم** — نظام بصري موحد فعليًا: مصدر رموز واحد (327 سطرًا) تستهلكه الملفات التسعة؛ 3 لوحات→1؛ 6 أزرار→هندسة واحدة؛ 3 تبويبات→قاعدة واحدة (ذهبي 13/600 مقيس في التبويبات الثلاثة)؛ ~15 شارة→مفردة دلالية واحدة (حي أزرق/مكتمل أخضر/منتظر كهرماني/فاشل أحمر)؛ 5 مداخل mono→رمز واحد؛ 5 نقاط انكسار→مقياس موثق؛ z مزدوج→سلّم واحد بصفر قيم حرفية؛ الحالات الفارغة/التحميل/الخطأ مصممة كحالات منتج (بطل مهيكل + سطور إرشاد + بطاقات dashed)؛ لا زخرفة تخفي تعقيدًا — التمييز من الهيكل (شهد به المراجع المستقل: «هندسة حقيقية لا إعادة تسمية»).

**الجودة الوظيفية** — كل العقود خضراء وأكثر مما كانت (96→97+27)؛ الإصلاحات الأربعة الوظيفية موثقة داخل الكود ومتحقق منها حيًا؛ لا بيانات وهمية (كل اللقطات ببيانات SQLAlchemy/API فعلية والحالات الفاشلة تُعرض بفشلها الصادق)؛ صفر أخطاء console في 6+ جلسات؛ لا تدهور طلبات (لم يُلمس أي منطق شبكة سوى إصلاح عقدة الإيقاف المعطلة).

**جودة الهندسة** — الشيفرة منظمة بقسمة معمارية معلنة (كروم/محتوى/أسطح)؛ صفر تعديل خارج `src/ui/` (git diff حرفيًا)؛ styles.css تحت سقفه بعد خرق موروث؛ كل تعديل قابل للمراجعة بالالتزامين المنفصلين دلاليًا (تأسيس ثم معالجة مراجعة)؛ كل الادعاءات مربوطة بأدلة قابلة للتكرار (سكربتات محفوظة + لقطات + JSON قياس).

**إثبات التسليم (البنود العشرة)** — ① تقرير النقد ① + ② مصفوفة المنافسين ② + ③ نظام التصميم وقرارات المعلومات ③ + ④ سجل التغييرات ④ + ⑤ صور قبل/after لكل شاشة ومقاس مستهدف (44+45) + ⑥ تقارير الاختبارات ⑤ + ⑦ المراجعة المستقلة ⑥ + ⑧ هذه القائمة + ⑨ SHA النهائي أدناه + ⑩ تعليمات المعاينة والتراجع في ④.
