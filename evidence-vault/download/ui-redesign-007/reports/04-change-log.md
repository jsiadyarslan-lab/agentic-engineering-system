## 4. طريقة المعاينة والتراجع (بند 10 من معايير التسليم)

**معاينة محلية** (لا تلمس الإنتاج):
```bash
git clone https://github.com/jsiadyarslan-lab/agentic-engineering-system.git
cd agentic-engineering-system && git checkout aes-ui-premium-redesign-007
PYTHONPATH=src python3 -m uvicorn src.api.routes:app --host 127.0.0.1 --port 8090
# ثم افتح http://127.0.0.1:8090/
```
**المعاينة الحية على Oracle غير متاحة ضمن هذه المهمة** حرفيًا كما نص الأمر (المرحلة 7: لا نشر ولا تغيير توجيه Nginx) — القرار النهائي للدمج والنشر بيد المالك بعد المراجعة. عند اعتماده: الدمج `--no-ff` ثم نفس مسار النشر الموثق في 005/006 (verify → bundle → ff-only → restart).

**التراجع عن المرشح**: حذف الفرع كفاية — لا أثر على main أو الإنتاج إطلاقًا (`git push origin --delete aes-ui-premium-redesign-007` + حذف worktree محليًا إن وُجد).
