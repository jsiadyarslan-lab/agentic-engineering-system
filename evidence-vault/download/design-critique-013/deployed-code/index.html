الإعدادات

عام

حالة النظام والركيزة وبيئة التنفيذ الفعالة — بلا أسرار.

المزودون والاتصال

إدارة كاملة من هنا: أضف مزودًا، عدّل Base URL، أضف تكوينات، واختبر الاتصال — المفاتيح محلية ولا تُعاد أبدًا.

إعدادات النماذج

لكل دور نموذجه المستقل — لا دور يرث مزود دور آخر.

الأدوات والقدرات

جرد حقيقي لقدرات النظام قبل أي مهمة — لا «جاهز» بلا مسبار فعلي، والجاهزية تنتهي صلاحيتها. البحث قدرة قابلة للتوفير: DDG مهلة ≠ الإنترنت مقطوع.

مزودو البحث

ابحث عبر أول مزود جاهز — جهّز SearXNG (رابط) أو Search API (نقطة+مفتاح) عند تعطل DDG.

بيئات التنفيذ

المسبار والمنفذ من مصدر واحد — بيئة جاهزة فقط بعد فحوص إقلاع/كتابة/تنفيذ/التقاط حقيقية. للتنفيذ على Linux/WSL2: شغّل العامل ثم أضف بيئة REMOTE_WORKER.
