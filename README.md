# Agent Hub v2

نظام وكلاء حقيقي: محادثة بسيطة + تنفيذ موثوق معزول + نتائج ملموسة + شفافية كاملة.
الهدف أن يستخدمه صاحبه بسهولة ChatGPT/Claude/Qwen — رسالة تُكتب، عمل يُنفَّذ بأمان،
نتيجة تُسلَّم بأدلة قابلة للفحص.

> **الحالة الحالية: الأمر الرابع (المعدل) — محرك الأوامر التنفيذية (EOE) + محركات الوصول والتنفيذ والدفع.**
> فوق الدورة الكاملة وحزم الموجّه الثلاث، يستقبل v2 الآن أمرًا تنفيذيًا
> منظمًا (أقسام §، عقد، شروط توقف، قالب تقرير) وينفذه فعليًا: منح وصول
> موقعة HMAC تُصدر بموافقة المالك عبر بطاقات في الواجهة، تنفيذ حقيقي داخل
> الركيزة المعزولة بقائمة بيضاء، والتزام داخل العزل بحدود انفجار ثم دفع
> بموافقة مالك موقعة **أحادية الاستخدام** (nonce لا يُعاد) مع استرجاع
> تلقائي بشهادة عند الفشل. أمر المالك (تدقيق تعبيئة الدروس) نُفّذ READ_ONLY
> على مخزن v1 الحقيقي بإثبات كتابة-صفر مزدوج وتقرير بالقالب الحرفي.
> 122 اختبارًا أخضر. لا استدعاءات LLM حقيقية بعد (تأتي مع أمر الاستدعاءات).

## ما يميز v2 عن v1

| الجانب | v1 (agent-hub) | v2 (هذا المستودع) |
| --- | --- | --- |
| الأدوار | أربعة (المفكر/المدقق/المنفذ/المراقب) — المراقب ضعيف | **خمسة** بإضافة المُحكَّم الذي يمنع الدوران اللانهائي |
| الحالات | 13 حالة تراكمت عبر 19 مرحلة | **11 حالة صادقة** + حُكمَان فرعيان، بلا SUCCESS مزيف |
| التنفيذ | Popen مباشر على المضيف (مهلة فقط) | **ركيزة عزل أصلية**: namespaces + seccomp + rlimits + watchdog |
| المنسق | 4,510 سطرًا ينفّذ وينسّق | **نحيف (<800 سطر)**: ينسّق فقط، المنطق في الأدوار |
| الواجهة | متمركزة حول الخطة والتبويبات | **متمركزة حول المحادثة** (نمط Claude) بأحادية لونية صارمة |
| الموافقات | تصنيف نصي بلا توقيع | منح موقعة HMAC + إيجار أحادي الاستخدام |

## المبادئ الخمسة

1. **المحادثة أولًا** — المحادثة هي التطبيق؛ كل شيء آخر يظهر داخلها.
2. **الصدق قبل الراحة** — لا حالة SUCCESS؛ `EXECUTED ≠ EVIDENCED ≠ VERIFIED`،
   ولا دور يمنح نفسه VERIFIED — القرار النهائي للمستخدم دائمًا.
3. **التنفيذ معزول أو معلن** — كود الوكلاء يعمل داخل الركيزة المعزولة،
   وإن تعذّر ذلك يُعلن الوضع المتوافق صراحةً بلا تدهور صامت.
4. **المنسق ينسّق لا ينفّذ** — سقف 800 سطر التزام دائم لا حالة عابرة.
5. **العقود قبل الكود** — كل تواصل بين الأدوار عبر عقود JSON صارمة موثقة في
   [CONTRACTS.md](CONTRACTS.md).

## التشغيل

### على Windows (الطريقة السريعة)

```powershell
# من جذر المشروع (أول مرة فقط — ينشئ البيئة ويثبت التبعيات):
.\scripts\setup.ps1
# أو بالنقر المزدوج: scripts\setup.cmd

# تشغيل الخادم (يفتح المتصفح تلقائيًا فور الجاهزية):
.\scripts\run.ps1
# أو بالنقر المزدوج: scripts\run.cmd

# للإيقاف: Ctrl+C
```

لا حاجة لتغيير سياسة التنفيذ — ملفات `.cmd` تمرر `-ExecutionPolicy Bypass`
داخليًا. `run.ps1` ذاتي الإصلاح: إن لم توجد البيئة يستدعي التجهيز تلقائيًا،
وإن نقصت حزمة يعيد التثبيت مرة قبل أن يتوقف.

### يدويًا (أي منصة)

```bash
python -m venv .venv
# Linux/WSL2:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1

pip install -e ".[test]"
pytest                                   # كل الاختبارات (بما فيها السالبة الأربع)
uvicorn api.routes:app --port 8010       # ثم افتح http://127.0.0.1:8010
```

## قيد المنصة

ركيزة العزل الحقيقية (namespaces + seccomp) تعمل على **Linux/x86_64 فقط** —
على Windows عبر WSL2. خارجها يعلن النظام الوضع المتوافق صراحةً ولا يكذب.
التفصيل: [src/substrate/README.md](src/substrate/README.md).

## العلاقة بـ v1

v1 (agent-hub) يبقى يعمل ويخدم صاحبه يوميًا حتى يغطي v2 كل قدراته بنسخة
أفضل — لا فترة يكون فيها النظامان معطلين، ولا ترحيل قبل اكتمال البديل.
ما يُنقل لاحقًا (الأدوات المضمّنة، الوصفات، البعثات الحية) موثق في
خطة الهجرة؛ الحزم الثلاث الأولى نُقلت في الأمر الثالث كوحدات مستقلة
في `src/router/` بتكافؤ مثبت ضد كود v1 نفسه (ARCHITECTURE.md §12).
